Blueberry Farm
Requirements
- Lv. 260 - Lv. 300 characters (Lv. 260 - Lv. 300 Zero characters must have completed Story Quest Act 2).
How to Participate
- Use a Blueberry Farm Entry Pass, then select 'Blueberry Farm' from the Event List to move to the Blueberry Farm Entrance. Talk to Miho to enter Blueberry Farm.
- Defeat Blueberries to help with the harvest and earn EXP based on your level.
Blueberry Farm Details
- Blueberry Farm has a 30-minute time limit. You can enter for up to 24 hours after using an entry pass.
- EXP buff effects are not applied while inside Blueberry Farm, and Multi-Kills do not occur.
- Lv. 280 and above characters earn the same EXP as a Lv. 279 character.
- Defeat the Giant Blueberry to bring the harvest to 100% and automatically exit the farm.
- If you exit before the harvest reaches 100%, you can re-enter Blueberry Farm before the time limit ends.
- You can use your next entry pass once the current harvest reaches 100% or when the time limit ends.
- Blueberry Farm Entry Passes can be obtained from the Challenger Pass.

NEW UPDATES
Enhancement Changes
Auto-Enhancement
- Added an Auto-Enhancement feature which automatically resets enhancements until a set target is reached. This feature is available for Star Force, Bonus Stats, Potential, and Bonus Potential in the Enhance UI. An Auto-Enhancement feature is also available for Ability resets.
- Star Force: Set a target Star Force level and choose an Enhancement Mode level. Enhancement Mode settings replace the previous Safeguard settings.
- 15 - 17 Stars: Enhancement Mode Lv. 1 - 3 or Safeguard can be selected.
- 18 - 21 Stars: Enhancement Mode Lv. 1 - 4 can be selected.
- Bonus Stats: Set target Bonus Stats for automatic resets.
- Bonus Stat auto-reset can be used with Powerful, Burning, Eternal, Black, and Abyssal Rebirth Flames, as well as Bonus Stat resets using mesos.
- Targets can be set up to Tier 7. Powerful and Burning Rebirth Flames can only be used to set targets up to Tier 6.
- Potential and Bonus Potential: Set target Potential options for automatic resets.
- Available only for Legendary-rank items.
- Ability: Set up to six target lines for automatic Ability resets. Auto-Enhancement stops when a target option matches the selected rank and has a value equal to or greater than the specified value, or when you don't have enough Honor EXP.
- Auto-Enhancement cannot be used for Star Force enhancements with Advanced Equip. Enhancement Scrolls or Equipment Enhancement Scrolls.
- Auto-Enhancement stops if you are automatically moved to another channel during channel maintenance.
General Enhancement Changes
- The Trace Restoration and Star Force Restoration will be combined into one tab as 'Trace Restoration'.
- Removed the Special Skill Ring Level Swap feature.

Guild Changes
Account Groups
- An Account Group feature has been added, allowing multiple characters in a world to act together as one guild member.
- When applying to join a guild, you can select up to 6 characters in the world to join as one guild member.
- Characters in an Account Group can access guild benefits like Guild Skills and Guild Noblesse Skills.
- Attendance, contribution, and guild content records are recorded 1 time per Account Group.
- For Sharenian Culvert, the highest score within the Account Group is recorded.
- If the character that achieved the highest Sharenian Culvert score in the Account Group leaves the guild, all records are reset.
- When a representative character is set in an Account Group, that character's name is always displayed to other guild members.
- You can leave an Account Group with an individual character, or leave the guild with the entire Account Group at once. Guild leaders cannot use the mass-leave function, and the representative character cannot leave the guild.
- When a guild member is expelled, all characters in their Account Group are expelled.
- Guild weekly missions can be participated in once per Account Group.
Guild Recruitment/Management
- Added an option so you can set the minimum character level required to join your guild.
- Added an Auto-Join option to the guild joining method. When an application meets the guild's joining conditions, the character automatically joins the guild without administrator approval.
- Improved the search and filter functions in Guild Search and the Recruitment Board.
- A guild can now receive up to 200 membership applications at the same time.
- Changed the method of creating an Alliance: 2 guild leaders can create an Alliance without forming a party and can then invite members afterward.
- Ranks with access to permissions can now delete intermediate ranks. When a rank is deleted, lower ranks move up one rank.
- The Guild UI has been changed.

Special Skill Ring
Special Skill Rings can now be obtained through crafting!
How to Participate
- Accept the '[Neon's Research] Call from Veritas' quest from the lightbulb notifier on the left side of the screen to start, and then talk to Neon to access the Special Skill Ring UI.
Ring Box Crafting
- Use Ardent Essence, obtained from extracting Special Skill Rings to craft Green, Red, Black, and White Boss Ring Boxes.
- There's a base success rate for each box you want to craft. Use the slider to add more materials and increase the success rate.
Ring Fusion
- Fuse three owned Special Skill Rings of the same level to obtain one random Special Skill Ring of that level.
- Only Lv. 1 - 4 Special Skill Rings can be used for fusion. Lv. 5 - 6 rings cannot be used.
Ring Extraction
- Extract owned Special Skill Rings to obtain Ardent Essence.

- At least 1 Projected Weekly Power is required to begin a new training session.
- Projected Weekly Power is consumed as players progress through the dungeon and can be restored when advancing to the next sector or with recovery potions obtained in the Proving Fields.
